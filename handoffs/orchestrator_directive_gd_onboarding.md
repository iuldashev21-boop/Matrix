# Orchestrator Directive: Game Design Agent

## Task: Design Emotional Onboarding Questionnaire

### Context
You are the Game Design agent for "The Construct" - a Matrix-themed habit tracking app. The app has core functionality working (habit tracking, streaks, check-ins, rewards). Now we need to design an emotionally engaging onboarding questionnaire.

### Current Onboarding Flow
1. Terminal Wake Up (typing animation, "Wake up Neo" style)
2. Pill Choice (red pill = continue)
3. First Hack Setup (user picks their first habit)
4. → Command Center (main app)

### The Problem
Users go through cool visuals but aren't emotionally invested. We need questions that make users confront their situation and commit psychologically BEFORE they start tracking habits.

### Your Task
Design an onboarding questionnaire that:

1. **Gets users emotionally invested** - not just collecting data
2. **Makes users self-reflect** - confront their reality
3. **Fits the Matrix theme** - feels like a system diagnostic, not a survey
4. **Builds anticipation** - creates tension before the "red pill" moment
5. **Doesn't feel like friction** - engaging, not tedious

### What to Propose
- The questions themselves (exact wording)
- The sequence/emotional arc
- How each question is framed visually (Matrix style)
- Answer format (multiple choice, slider, free text, etc.)
- Where in the flow these questions appear (before pill choice? after? split?)
- Estimated time to complete
- What we do with responses (even if just for user's own reflection)

### Psychological Principles to Consider
- Commitment/consistency bias
- Self-perception theory
- Sunk cost (time invested = more likely to continue)
- Emotional priming
- The "fresh start effect"

### Important Instruction
**DO NOT finalize your proposal without discussing with the user first.** Present your initial ideas and options, ask for feedback, and iterate based on user input before delivering final recommendations.

### Deliverable
Save your proposal to: `handoffs/gd_proposal_onboarding_questionnaire.md`

### Tone
Matrix-inspired but not corny. Serious, slightly ominous, makes user feel like they're being analyzed by something that understands them.
